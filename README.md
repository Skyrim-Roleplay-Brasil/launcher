## Release público

| Componente | Valor |
|---|---|
| Launcher estável | `1.7.9` |
| Skyrim recomendado | `1.7.104.0` |
| Skyrim suportado | `1.6.1170.0`, `1.7.99.0`, `1.7.104.0` |
| Manifesto | [`manifest.json`](manifest.json), cópia do manifesto servido em produção |

O launcher lê o manifesto em `https://api.skyrimrp.com.br/launcher/manifest.json`. A atualização automática usa o canal do CDN oficial, não os releases deste repositório.

O [`manifest-v2.json`](manifest-v2.json) é **histórico** (perfil `client-1.7.99`, launcher 1.6.3, agosto de 2026) e não é servido em produção.

## Download

Baixe pela [página de download](https://skyrimrp.com.br/download).

1. Baixe `SkyrimRP-Launcher-Setup-1.7.9.exe`.
2. Confira que o arquivo veio de `skyrimrp.com.br` ou do CDN oficial `cdn.skyrp.com.br`.
3. Instale, autentique e deixe o launcher validar e baixar os pacotes do cliente.

> Requisito: cópia original de *The Elder Scrolls V: Skyrim Special Edition* (Steam). Versão recomendada `1.7.104.0`.
